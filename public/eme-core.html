Game Launcher WinUI 3 .NET 8.0

E.M.E Core

Launcher de jogos desktop nativo para Windows — organize, descubra e jogue seus jogos favoritos. Inspirado no Steam.

Download Ver no GitHub

Funcionalidades

Scanner Automático

Detecta jogos Steam, Xbox/Game Pass e pastas comuns (C:\Games, D:\Games).

Biblioteca Visual

Grid com capas reais via Steam Store API, busca por nome e filtros por plataforma.

Monitor de Hardware

CPU, GPU, RAM, temperaturas, fans, FPS em tempo real. Cards colapsáveis.

Conquistas

Parser de saves (Stellar Blade, God of War, Cyberpunk), notificação com som estilo Steam.

100% Offline

Banco SQLite local. Sem dependência de nuvem. Seus dados ficam no seu PC.

Nativo Windows

C# WinUI 3, baixo consumo de RAM/CPU. Performace premium.
